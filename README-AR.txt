Reda Note - مشروع أندرويد (الإصدار 1.1)
=====================================

هذا مشروع Android يضم تطبيق Reda Note داخل WebView محلي، لذلك لا يحتاج التطبيق إلى الإنترنت أثناء الاستخدام.

ما الجديد في الإصدار 1.1؟
- إكمال المواد العشر لشعبة البكالوريا: رياضيات، فيزياء، علوم طبيعية، عربية، إنجليزية، فرنسية، تاريخ، جغرافيا، فلسفة، وعلوم إسلامية.
- زر «قراءة كاملة» للملاحظات الطويلة مع مساحة قراءة قابلة للتمرير، دون الدخول إلى وضع التعديل.
- التفاف عناوين المهام وتفاصيلها على أكثر من سطر حتى لا تتجاوز حدود الشاشة.
- تخصيص مدة التركيز من دقيقة واحدة إلى 120 دقيقة، والاستراحة من دقيقة إلى 30 دقيقة.
- إشعار أندرويد واهتزاز اختياريان عند انتهاء جلسة التركيز، بعد منح صلاحية الإشعارات.
- عدّاد بسيط لجلسات التركيز المكتملة.
- الاحتفاظ بإعدادات المؤقّت ضمن ملف النسخ الاحتياطي JSON.

البيانات والتوافق:
- لم يتغير مفتاح تخزين الملاحظات والمهام أو معرّف التطبيق، ويقرأ الإصدار 1.1 بيانات الإصدار 1.0 الموجودة على الجهاز عند تثبيت تحديث متوافق التوقيع.
- مع ذلك، صدّر نسخة JSON قبل التحديث كإجراء احتياطي. إذا رفض أندرويد تثبيت APK كتحديث بسبب اختلاف توقيع البناء، لا تحذف التطبيق مباشرة: صدّر JSON أولاً، ثم احذف الإصدار القديم وثبّت الجديد واستورد النسخة الاحتياطية.
- النسخ الاحتياطي يحفظ الملاحظات والمهام وإعدادات مؤقّت التركيز. عدّاد جلسات التركيز يبقى على الجهاز ولا يدخل في ملف النسخة الاحتياطية.
- إشعار نهاية الجلسة يحتاج تفعيل صلاحية الإشعارات من داخل إعدادات التطبيق. يعمل التنبيه داخل التطبيق حتى دون منح الصلاحية.

بناء APK من الهاتف عبر GitHub Actions:
1. استبدل ملف Reda-Note-Android-Phone-Build.zip الموجود في مستودع GitHub بهذه الحزمة الجديدة، مع الإبقاء على الاسم نفسه لأن سير العمل الحالي قد يعتمد عليه.
2. اترك ملف build.yml الحالي الذي نجح معك كما هو، ما لم تظهر مشكلة في مسار فك الضغط.
3. افتح تبويب Actions، وشغّل Build Reda Note APK إن لم يبدأ تلقائيًا.
4. بعد نجاح البناء، افتح نتيجة التشغيل ثم Artifacts وحمّل Reda-Note-APK-v1.1.zip.
5. فك ضغط الملف لتحصل على app-debug.apk. جرّب تثبيته كتحديث أولاً. إن رفض أندرويد بسبب التوقيع، اتبع تعليمات النسخ الاحتياطي أعلاه قبل حذف التطبيق القديم.
