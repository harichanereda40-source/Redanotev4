Reda Note v1.1 - Android source project

مهم: ارفع محتويات هذا الملف المضغوط إلى جذر مستودع GitHub، ولا ترفع ملف ZIP نفسه.
يجب أن تظهر في جذر المستودع الملفات والمجلدات التالية:
app/ ، build.gradle ، settings.gradle ، gradle.properties

ثم أنشئ ملف GitHub Actions بالمسار:
.github/workflows/android-apk.yml
والصق محتوى ملف android-apk-workflow.yml المرسل منفصلًا.

بعد حفظ الملفات افتح Actions وشغّل Build Reda Note APK.
بعد نجاح البناء افتح تفاصيل التشغيل ثم Artifacts ثم نزّل Reda-Note-APK-v1.1.

احتفظ بنسخة JSON الاحتياطية من التطبيق القديم قبل تثبيت النسخة الجديدة.
